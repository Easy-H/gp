# Notation

Notation은 소스 코드를 분석해 클래스 구조와 관계를 시각화하는 웹 애플리케이션입니다.

체스 기보처럼 코드 구조를 읽고 기록한다는 방향으로 이름을 정했으며, 분석 결과를 패널 단위로 나누어 소스 코드, 클래스 상세, 다이어그램, 다이어그램 편집 화면을 자유롭게 배치해 볼 수 있습니다.

## 주요 기능

- 코드에서 클래스, 인터페이스, 멤버, 상속, 구현, 연관 관계 추출
- 단일 파일 코드 직접 입력 분석
- ZIP 프로젝트 업로드 분석
- 로컬 Git 폴더 분석
- 원격 Git 저장소 분석
- 패널 기반 분석 결과 화면
- 소스 코드 보기, 클래스 상세 보기, 클래스 다이어그램 보기
- 다이어그램 편집 패널 추가 및 Mermaid 텍스트 수정
- 다이어그램 확대, 축소, 리셋, 맞춤
- 라이트 모드와 다크 모드 전환
- Mermaid, PlantUML, Graphviz DOT, PNG 내보내기

## 분석 결과 화면

분석 결과는 패널 레이아웃 위에서 동작합니다. 기본 화면은 다음 패널로 구성됩니다.

- `소스`: 선택한 클래스의 원본 코드와 코드 검색 결과를 확인합니다.
- `상세`: 클래스의 필드, 메서드, 상속, 구현, 연관 관계를 확인하고 일부 정보를 편집합니다.
- `다이어그램`: Mermaid 기반 클래스 다이어그램을 렌더링합니다.

상단의 `+` 버튼을 사용하면 패널을 추가할 수 있습니다.

추가 가능한 패널은 다음과 같습니다.

- `소스`
- `상세`
- `다이어그램`
- `다이어그램 편집`

## 입력 방식

`새 프로젝트 분석하기` 버튼을 누르면 분석 모달이 열립니다.

지원하는 입력 방식은 다음과 같습니다.

- `코드 직접 입력`: 코드 조각을 붙여넣고 언어를 선택해 분석합니다.
- `Git 저장소 (.git)`: 원격 Git URL 또는 로컬 Git 폴더를 분석합니다.
- `프로젝트 업로드 (Zip)`: ZIP으로 압축한 프로젝트를 업로드해 분석합니다.

## 관계 추출 기준

관계 추출은 언어별 AST를 기반으로 수행합니다. 현재는 다음 정보를 주요 신호로 사용합니다.

- 클래스가 보유한 멤버 변수
- 함수 또는 메서드 매개변수
- 상속과 인터페이스 구현
- JavaScript에서 `new`가 포함된 멤버 대입
- Java, Spring Boot 코드의 필드 주입 및 생성자 주입 패턴

## 내보내기

지원 형식은 다음과 같습니다.

- `.mmd`
- `.puml`
- `.dot`
- `.png`

## 내부 구조

주요 흐름은 다음과 같습니다.

1. `App`이 전체 화면 상태, 테마, 모달, 패널 구성을 조립합니다.
2. `useAnalyzerBootstrap`이 Tree-sitter 분석기를 초기화하고 언어 파서를 준비합니다.
3. `useProjectAnalysis`가 직접 입력, ZIP, Git 기반 분석을 실행합니다.
4. `AnalysisPanelWorkspace`가 패널 레이아웃과 분석 결과 패널을 구성합니다.
5. `details`, `source`, `diagram` feature 폴더가 각 패널의 화면을 담당합니다.
6. `Exporter`가 Mermaid, PlantUML, DOT 내보내기 문자열을 생성합니다.

## 실행 방법

의존성을 설치합니다.

```bash
npm install
```

개발 서버를 실행합니다.

```bash
npm run dev
```

프로덕션 빌드를 생성합니다.

```bash
npm run build
```
